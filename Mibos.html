Kurikulum MI

Manajemen Informatika (D-III)

Program Studi Manajemen Informatika (MI) adalah program vokasi Diploma Tiga (D-III) yang berfokus pada perpaduan keahlian di bidang Sistem Informasi, Pengembangan Aplikasi, dan Manajemen Bisnis. Kurikulum kami dirancang untuk menghasilkan Ahli Madya yang siap langsung terjun ke dunia kerja sebagai penghubung antara kebutuhan bisnis dan solusi teknologi.

Mahasiswa akan dibekali keterampilan praktis dalam pemrograman web dan mobile, desain dan implementasi basis data, serta analisis dan perancangan sistem informasi. Lulusan MI memiliki kompetensi spesifik yang dibutuhkan oleh perusahaan, terutama sebagai Programmer, Web Developer, dan Mobile Application Developer yang mampu membangun sistem untuk meningkatkan efisiensi operasional.

Profil Lulusan Utama
  • Programmer: Mampu menulis, menguji, dan memelihara kode pemrograman untuk aplikasi bisnis.
  • Web Developer: Kompeten dalam merancang, mengembangkan, dan memelihara situs web serta aplikasi web.
  • Mobile Application Developer: Mampu merancang dan mengembangkan aplikasi mobile (Android/iOS).
  • System Support/Administrator: Ahli dalam pemeliharaan dan dukungan sistem informasi perusahaan.
Fokus Akademik
  • Analisis dan Perancangan Sistem Informasi Bisnis.
  • Pemrograman Berorientasi Objek dan Framework Pengembangan.
  • Basis Data Lanjut (SQL dan NoSQL).
  • Teknologi Cloud dan Web Service.
