Teknologi Rekayasa Perangkat Lunak

Program Studi Sarjana Terapan Teknologi Rekayasa Perangkat Lunak (TRPL) didirikan untuk memenuhi kebutuhan industri akan profesional pengembang perangkat lunak yang terampil. Fokus pada pengajaran metodologi pengembangan perangkat lunak yang efektif, mulai dari analisis kebutuhan, perancangan, implementasi, pengujian, hingga pemeliharaan. Program studi ini menekankan pada kualitas, keamanan, dan penggunaan teknologi terkini seperti Agile, DevOps, dan Cloud Computing.

Lulusan TRPL dipersiapkan menjadi System Analyst, Database Programmer, Senior Programmer, atau Software Engineer yang mampu merancang dan mengimplementasikan solusi perangkat lunak yang kompleks dan berkualitas tinggi untuk berbagai sektor industri.

Profil Lulusan Utama
  • System Analyst: Mampu menganalisis dan merancang perangkat lunak sesuai kebutuhan pengguna.
  • Software Engineer: Mampu mengembangkan, menguji, dan memvalidasi sebuah perangkat lunak.
  • Database Programmer: Ahli dalam mendesain, mengimplementasikan, dan mengelola basis data.
  • Senior Programmer: Mampu mendesain dan mengelola pembuatan program, web, dan aplikasi.
Fokus Akademik
  • Rekayasa Perangkat Lunak Tingkat Lanjut.
  • Pengembangan Aplikasi Mobile dan Web Modern.
  • Data Science dan Kecerdasan Buatan (AI) Dasar.
  • Keamanan Siber dan Pengujian Perangkat Lunak.
